# Sky Sales Portal — مسار تحديث الشريحة

**الهدف النهائي:** `requests` عادي (session + cookies) — **بدون** Playwright.

**اللوحة:** https://sales-ps.sky5g.ps/

---

## مسار الواجهة (UI)

```
تسجيل دخول (+ OTP SMS)
  → ادارة الزبائن
  → زبون قائم
  → بحث: رقم الهاتف / اسم الزبون / رقم الشريحة
  → اختيار النتيجة
  → اختار عملية → تحديث الشريحة
```

## بيانات الزبون (مثال `0555544071`)

| حقل | قيمة |
|-----|------|
| اسم الزبون | حمزة وليد نعيم |
| شركة الاتصالات | سلكوم |
| رقم الشريحة | 899720206491380371 |
| رقم الهاتف | 0555544071 |
| حالة الشريحة | مفعل |

## تنسيق الرد الموحّد

كل الحالات ترجع JSON بنفس الهيكل:

```json
{
  "success": true,
  "message": "...",
  "phone": "0555544071",
  "reason": "..."
}
```

| reason | success | message | حقول إضافية |
|--------|---------|---------|-------------|
| `success` | `true` | `تم التحديث بنجاح - رقم العملية: ...` | `task_id`, `status_name`, `status_id` |
| `not_active` | `false` | `لم يتم التحديث` | `status_name`, `status_id` |
| `not_found` | `false` | `لم يتم التحديث` | — |
| `not_eligible` | `false` | `لم يتم التحديث` | — (Sky رجّع ERROR / cooldown) |
| `proxy_error` | `false` | `فشل الاتصال — تحقق من البروكسي` | `error` |
| `connection_error` | `false` | `فشل الاتصال بـ Sky` | `error` |
| `login_error` | `false` | `فشل تسجيل الدخول` | `error` |
| `session_error` | `false` | `انتهت الجلسة` | `error` |
| `otp_required` | `false` | `مطلوب كود OTP` | `otp_required: true`, `error` |
| `config_error` | `false` | (حسب الخطأ) | `error` |
| `api_error` | `false` | `خطأ أثناء التحديث` | `error` |

**exit code:** `0` لكل الحالات، `2` فقط إذا `otp_required: true`.

## شرط قبل التحديث

**لا يُنفّذ التحديث إلا إذا `status_name == مفعل`** (من بيانات Sky مباشرة).

غير ذلك → `success: false` + `message: لم يتم التحديث` + `status_name` + `status_id` من API.

## حالات مرصودة من Sky (بدون تصنيف إضافي)

| status_id | status_name | ملاحظات |
|-----------|-------------|---------|
| `301` | مفعل | الحالة الوحيدة المسموح التحديث فيها |
| `1304` | مفصول-استقبال مكالمات | `0502251459` — `days_to_end_of_plan: -27` |

## حالات API المتوقعة (نختبر كل رقم)

| # | الحالة | رقم الاختبار | ملاحظات |
|---|--------|--------------|---------|
| 1 | نجاح التحديث | `0555544071` | `status_name: مفعل` → `data[0].ID` → **تم التحديث بنجاح** |
| 2 | الرقم غير موجود | (تزود) | لا نتائج بحث |
| 3 | غير مفعل | `0502251459` | `status_name: مفصول-استقبال مكالمات` → **لم يتم التحديث** |

## ما نلتقطه من Network

لكل خطوة نسجّل:

- URL + Method
- Headers (خصوصاً `Cookie`, `Authorization`, `X-*`)
- Request body (JSON/form)
- Response body + status

## الفرق عن `rn.sky-5g.net`

| | لوحة المبيعات `sales-ps.sky5g.ps` | الصفحة العامة `rn.sky-5g.net` |
|---|---|---|
| Auth | login + OTP + session | reCAPTCHA v3 |
| التحديث | بعد بحث زبون + عملية | POST مباشر برقم |
| الهدف | API داخلي بموظف | API عام |
