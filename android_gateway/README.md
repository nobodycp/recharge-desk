# بوابة رسائل بروسيم — تطبيق أندرويد

تطبيق أصلي (Kotlin) يحوّل هاتف أندرويد إلى بوابة SMS لخدمة تحديث الأرقام:

1. يستقبل رسالة المشترك (كتطبيق الرسائل الافتراضي) ويرسلها للسيرفر.
2. يستخرج السيرفر الرقم (`05[0-5]` + 7 أرقام)، يحدّثه عبر الـ API، ويضع الرد في الطابور.
3. يسحب التطبيق الرد كل بضع ثوانٍ ويرسله للمرسل، ثم يبلّغ السيرفر بالتسليم.

> لأن التطبيق هو **تطبيق الرسائل الافتراضي**، الرسائل الواردة لا تُحفظ أصلاً في
> صندوق الوارد، فلا يمتلئ الهاتف.

## الحصول على APK جاهز (بدون تثبيت برامج)

البناء آلي عبر GitHub Actions (الملف `.github/workflows/android.yml`):

1. ارفع المشروع إلى GitHub (أي تعديل داخل `android_gateway/` يشغّل البناء)، أو
   شغّله يدوياً من تبويب **Actions → Build Android APK → Run workflow**.
2. بعد نجاح البناء، افتح صفحة الـ run واسحب الملف من قسم **Artifacts**:
   `prosim-sms-gateway-debug` (بداخله `app-debug.apk`).
3. انقل الـAPK إلى الهاتف وثبّته (فعّل "تثبيت من مصادر غير معروفة").

## البناء محلياً (اختياري)

```bash
cd android_gateway
gradle assembleDebug      # أو: ./gradlew assembleDebug إذا ولّدت الـwrapper
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

يتطلب JDK 17 و Android SDK (Platform 34, Build-Tools 34).

## الإعداد على الهاتف

1. افتح التطبيق وأدخل:
   - **رابط السيرفر**: مثل `https://s.prosim.ps` (النطاق الرئيسي — لا تستخدم
     نطاق التحديث العام `rn.prosim.ps`).
   - **توكن الجهاز**: من لوحة الإدارة ← تحديث الرسائل ← إعدادات ← الأجهزة ←
     أضف جهازاً وانسخ التوكن الخام (يظهر مرة واحدة).
   - **فترة سحب الردود**: 10 ثوانٍ افتراضياً.
2. اضغط **منح صلاحيات الرسائل** ووافق على الأذونات.
3. اضغط **اختبار الاتصال** للتأكد من صحة الرابط والتوكن.
4. اضغط **جعله تطبيق الرسائل الافتراضي** ووافق.
5. فعّل **تشغيل الخدمة** ثم **حفظ وتشغيل**.
6. (مهم) عطّل تحسين البطارية لهذا التطبيق حتى لا يوقفه النظام:
   إعدادات ← التطبيقات ← بوابة رسائل بروسيم ← البطارية ← غير مقيّد.

## بروتوكول السيرفر

نقاط الجهاز (مصادقة `Authorization: Bearer <token>`، خارج بادئة اللغة):

- `POST /sms-gateway/api/inbound/` — `{ "from", "text", "device_msg_id" }`
- `GET  /sms-gateway/api/outbox/?limit=10` — `{ "messages": [...], "delete_ids": [...] }`
- `POST /sms-gateway/api/delivery/` — `{ "sent": [...], "failed": [...], "deleted": [...] }`

## ملاحظات

- التطبيق نسخة debug غير موقّعة للتوزيع الداخلي (sideload)، وليست للنشر على المتجر.
- MMS وكتابة الرسائل غير مدعومين (التطبيق مخصص للبوابة فقط).
- دعم عدة هواتف: ثبّت التطبيق على أكثر من هاتف بتوكن مختلف لكل جهاز؛ السيرفر
  يوزّع الردود حسب الأولوية والتوفر.
