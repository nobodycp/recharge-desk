توثيق الواجهة البرمجية
جميع الحقول تُرسل بصيغة JSON. حدّث صفحتك بعد كل تعديل لإعدادات API.
{% if api_settings.require_token %} يتطلب توكن {% else %} بدون توكن {% endif %}
نقطة النهاية (Endpoint)
POST {{ api_endpoint }}
الترويسات (Headers)
Content-Type: application/json{% if api_settings.require_token %}
Authorization: Bearer <token>{% endif %}
{% if not api_settings.require_token %}
التوكن غير مطلوب حالياً (الإعداد require_token معطّل).
{% endif %}
جسم الطلب (Body)
{
  "phone_number": "0555555555"
}
phone_number سلسلة نصية مكوّنة من 10 أرقام تبدأ بـ 05.
مثال على استجابة 200
{
  "status": "refreshed",
  "message": {
    "title": "تم التحديث",
    "body": "تم تحديث الرقم بنجاح."
  },
  "last_refresh_at": "2026-05-25T01:00:00+03:00",
  "seconds_since_last_refresh": 0
}
الحقول last_refresh_at و seconds_since_last_refresh تظهر فقط عند تفعيل «عرض آخر تحديث للرقم» في تبويب الإعدادات العامة.
رموز الحالة المتاحة
{% for status in refresh_statuses %} {{ status.code }} — {{ status.label }} {% endfor %}
رموز HTTP المحتملة
  • 200 — استجابة طبيعية، الحقل status يحدّد النتيجة.
  • 400 — رقم هاتف مفقود أو غير صالح.
  • 401 — التوكن مفقود أو غير صالح (عند تفعيل اشتراط التوكن).
  • 403 — Origin غير مسموح به.
  • 429 — تجاوز حدود الطلبات (دقيقة/ساعة).
مثال curl
curl -X POST '{{ api_endpoint }}' \
  -H 'Content-Type: application/json'{% if api_settings.require_token %} \
  -H 'Authorization: Bearer YOUR_TOKEN'{% endif %} \
  -d '{"phone_number":"0555555555"}'
